# ANIMINFO Rev 1.0.0

ANIMINFO is a cross-port (universal) animation substitution lump that allows authors to add alias animations and widescreen assets to graphic lumps. Examples of included lumps include M_DOOM, M_SKULL1, TITLEPIC, INTERPIC, STBAR, etc.

The full specification is available [here](./docs/spec.md).
